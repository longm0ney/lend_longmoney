# Raif land + Telegram admin bot

Лендинг (тёмный/белый + гео) и Telegram-бот для смены CTA/домена/клоаки и статистики.

## Структура

```
public/          # ленд (отдаётся наружу)
bot/             # Node API + Telegram-бот (НЕ отдаётся статикой)
  src/
  .env.example
  data/store.example.json
```

## Быстрый старт

1. Node.js 18+
2. Скопируй env:
   ```bash
   cd bot
   cp .env.example .env
   ```
3. Заполни `.env`:
   - `BOT_TOKEN` — от @BotFather
   - `ADMIN_IDS` — твой Telegram id (обязательно)
   - `SERVER_PUBLIC_IP` — IP сервера для DNS-подсказок и проверки домена
4. Данные:
   ```bash
   mkdir -p data
   cp data/store.example.json data/store.json
   ```
5. Запуск:
   ```bash
   npm install
   npm start
   ```
6. Ленд: `http://127.0.0.1:8787/`

## Что в боте

- ссылка кнопки «Оформити»
- публичный URL/домен + инструкция DNS
- автопроверка домена (пуш, когда встал)
- клоака / гео
- статистика визитов и кликов

## Важно по безопасности

- **Не коммить** `.env` и `bot/data/store.json` — там токены, ссылки, статистика
- `ADMIN_IDS` обязателен: без него бот не стартует
- Статика отдаёт только `public/`, папка `bot/` снаружи недоступна
- `/api/event` с rate-limit (антинакрутка)
- На проде держи сервис за nginx/caddy + HTTPS

## Передача другому человеку

Отдай репозиторий. Получатель:

1. клонирует репо
2. создаёт свой `.env` (свой бот / свой id / свой IP)
3. создаёт `bot/data/store.json` из example
4. ставит DNS A на свой сервер и прописывает домен в боте

Твои токены и домен из репо **не уходят**, если не было ручного коммита секретов.
